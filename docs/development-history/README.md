# Development history archive

The main README is the v1.0 project brief. The earlier long-form README is
preserved as [`README-legacy.md`](README-legacy.md) so the Phase 1–25 design
decisions, regression notes, and historical observations remain auditable
without occupying the repository landing page.

The archive is historical evidence. Its model names, token counts, provider
results, and phase conclusions belong to the version and fixture recorded at
the time; they are not current v1.0 benchmark claims. The current repeatable
offline suite is in [`benchmark/`](../../benchmark/README.md).

The implementation history can be read alongside:

- [`HANDOFF_TO_CODEX.md`](../HANDOFF_TO_CODEX.md), the detailed engineering handoff;
- [`evaluation/REAL_RUN_LOG.md`](../evaluation/REAL_RUN_LOG.md), the redacted historical run log;
- [`experiments/README.md`](../experiments/README.md), the index for the moved JSON and phase artifacts.
