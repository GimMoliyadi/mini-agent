# Evaluation archive

This directory contains historical provider observations and their redacted
run log. These artifacts explain how the runtime evolved, but they are not a
replacement for Benchmark v1 and must not be combined into a single current
acceptance rate.

The current provider-free benchmark is under [`benchmark/`](../../benchmark/README.md).
Any live-provider run must record its model, fixture, valid denominator,
provider failures, and whether a result was deterministic or manually
reviewed.
