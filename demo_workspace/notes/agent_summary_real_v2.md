# Agent 学习摘要 (v2)

来源：`agent_notes.md`（已有前作 `notes/agent_summary.md`，本版更简短）

## 1. Agent 和聊天机器人差在哪

- 聊天机器人：一问一答，只"说"不"做"。
- Agent：自己决定下一步 → 动手做 → 看结果 → 继续做，直到任务完成。
- 真正的差别不是模型大小，而是**有没有工具 + 有没有循环**。

## 2. Agent 的核心循环

```
任务 → LLM 判断下一步 → 调用工具 → 拿到结果 → 再交给 LLM → ... → 完成
```

关键在第 4 步：工具的返回必须**回喂给 LLM**，LLM 才能据此改变策略。
只调一次工具就把结果打印出来，那只是"带函数调用的聊天"，不算 Agent。

## 3. 工具是什么

- 工具就是给 Agent 调用的普通函数（读文件、写文件、列目录、算数……）。
- 工具本身很笨——只执行、不判断；聪明的是 LLM，决定**何时用哪个工具、传什么参数**。
- 写工具的要点：
  - 参数尽量简单直观；
  - 报错信息要清晰具体——LLM 是根据返回值决定下一步的，含糊的报错会让 Agent 乱猜。

## 4. 本项目的约定

- **安全边界**：Agent 只能操作 `demo_workspace/` 内的文件，不许碰项目外内容。
  这是要在代码层面真正拦截的硬约束，而不是写在文档里的"愿望"。
- **工程节奏**：每新增一个能力，先跑通再继续。

## 5. 一句话总结

Agent = LLM 决策 + 工具执行 + 结果回喂 形成的闭环；工具要简单可靠、报错要清晰、安全边界必须在代码里真正落地。
