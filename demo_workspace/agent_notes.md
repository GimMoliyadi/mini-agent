# Agent 学习笔记

## 普通聊天机器人 vs Agent

- 聊天机器人：你问一句，它答一句，结束。它只会说，不会做。
- Agent：它自己决定要做什么，动手做，看结果，再继续做，直到任务完成。

差别不在模型大小，而在有没有「工具」和「循环」。

## 一个 Agent 循环长这样

```
任务 → LLM 判断下一步 → 调用工具 → 得到结果 → 再交给 LLM → ... → 完成
```

注意最后一环：工具的结果会**回喂**给 LLM，LLM 才可能改变下一步决定。
只调用一次工具、把结果直接打印出来，那只是"带函数调用的聊天"，还不是 Agent。

## 工具是什么

工具就是 Agent 能调用的普通函数，比如「读文件」「写文件」「列目录」「算数」。

工具本身很笨：它只是执行，不做判断。
聪明的是 LLM：它决定**什么时候**用哪个工具、**传什么参数**。

所以写工具时应该让参数尽量简单、错误信息尽量明确——
LLM 是根据返回内容决定下一步的，工具报错报得含糊，Agent 就会乱猜。

## 本项目的约定

- Agent 只能碰 `demo_workspace/` 里的文件，不许碰项目外的东西。
  这是必须真正拦截的安全边界，不是写在文档里的愿望。
- 每加一个能力，都必须先跑通再往下走。
